# Contribute a domain to Skill Atlas

A domain ships as JSON generated by the KTG prompt and gated by the validator.
The validator is the review bar (ticket 009): a PR that passes merges; there is
no separate human content review. Source of truth for the schema is
`ktg-prompt.md` at the repo root.

## 1. Generate the skeleton (Pass A)

1. Open `ktg-prompt.md`. Use it verbatim as the system prompt.
2. Say `SKELETON: <domain>`. The model emits the full tree: `domain`, `level`,
   `schools`, `clusters`, `spine`, and every node with only
   `id, label, tier, cluster, prereqs, one_line, hours`.
3. Each cluster MUST carry an `icon` field: one emoji. The renderers read it;
   a missing icon draws a fallback glyph and the validator warns.
4. Run the loud check from the prompt before you accept the output. The known
   failure (pilot, ticket 003): the spine drifts into one cluster's document
   chain instead of crossing the tree. Silent self-checks do not catch it.
5. Save verbatim to `domains/<slug>/skeleton.json`. Do not reformat.

Budget from the pilot: about 2 hours for a skeleton plus one loud-check
iteration.

## 2. Generate bodies (Pass B), spine first

1. Say `BODIES: <id>, <id>, ...` with the spine node ids first. Later batches
   stream in the long tail; the renderer treats missing bodies as honest
   pending state.
2. Save each batch to `domains/<slug>/bodies/batch-NNN.json`. Use the envelope
   `{ "domain", "batch", "ids", "nodes" }` (a bare array of node objects also
   validates).
3. Bodies only ADD `soft_prereqs`, `school_weights`, and the eight content
   sections. A body must not redefine skeleton fields or add nodes.

Budget from the pilot: about 3.5 hours for the spine bodies.

## 3. Validate — this is the merge gate

```bash
npm run validate            # all domains
node scripts/validate.mjs <slug>   # one domain
```

Fix every `ERROR`. Read every `WARN`; calibration warnings (spine length,
cluster count) are advisory but reviewers see them.

## 4. Regenerating an existing domain

Anyone may regenerate. Node ids are stable identifiers — the diff is the guard
and the audit trail:

```bash
node scripts/validate.mjs <slug> --against <previous-skeleton.json> --stability
```

Id drift fails the check. A regeneration that silently renumbers nodes does
not merge.

## 5. Open the PR

Include only `domains/<slug>/` files. CI runs the validator on every PR.
Domain experts who cannot run prompts open an issue naming the domain instead;
the maintainer generates it through the same gate.
